# Not so cool graphics editor
features:
- lines
- verteces
- 2D operations
- 3D operations
- Projection
- Save and Load functions
## Dependencies
- Raylib
- Raygui (you will probably need to compile it by youself)
## Building 
Command
```
g++ Raylib-based-CoolEditor/src/*.cpp -o Raylib-based-CoolEditor/src/editor -lraylib -lraygui
```
